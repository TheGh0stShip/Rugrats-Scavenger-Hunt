# BSS layout (VRAM 0x80057280..0x800C7E30, 0x70BB0 bytes, no ROM bytes)

Source of truth: `inventory/bss_layout.tsv`, generated by `python3 tools/bss.py scan`,
checked by `python3 tools/bss.py validate` (prints summary JSON, exit 1 on error).

## Derivation
* Code: per function (boundaries from survey `symbol_addrs.txt`), basic blocks are
  built from branch/jump targets and delay slots; a forward dataflow pass propagates
  register constants (lui, addiu/addi/daddiu, ori, addu of constants, move, li) and
  "constant + index" values (addu of a constant and an unknown) across blocks. Block
  entry = meet (equal values only) of predecessor exits; for likely branches the
  fall-through edge uses the state before the delay slot. Caller-saved registers
  are dropped after a call's delay slot.
  - `addr`: lui-hi + low-immediate address formation.
  - `mem`: load/store whose base register is a known constant (width/type recorded).
  - `indexed`: load/store whose base is constant + index (array element).
* Initialized data: aligned 32-bit words in .rodata/.data (ROM 0x103C..0x45F0,
  0x53474..0x57E80) whose value is inside BSS (`dataptr`).
* Clear calls: at `jal func_80038E90` (memset-like: a0 dst, a2 size) and
  `jal func_80051050` (bzero: a0 dst, a1 size), after the delay slot, when a0 is
  a known BSS constant and the size register is a known constant, the size is recorded.

## Sizing rules (in priority order)
1. Clear size from memset/bzero (`size=memset(0xN) in func...`); every reference
   inside it becomes an `alias` row (overlapping view, listed after the main rows,
   emitted as a macro in bss.h).
2. If the widest access runs past the next reference, the symbol is widened to that
   width and the inner reference becomes an `alias` (example: D_800C33BC s32 with
   D_800C33BE s16 view).
3. Only plain loads/stores of one width: symbol = that width (`size=access_width`),
   rest becomes `bss_gap_XXXXXXXX`.
4. Otherwise the symbol extends to the next reference (`size=next_ref`).
Element type: the single observed access type, else by width, else u8.
`align` = natural alignment of the start address capped at 8.

## Build check (executed)
`tests/test_bss.py::test_kmc_link_addresses` compiles `src/bss/bss.c` with KMC GCC
2.7.2 (`-G0 -mips3 -mgp32 -mfp32 -O2 -fno-common -DBSS_STANDALONE`), links with
mips-linux-gnu-ld using `src/bss/bss.ld` (NOLOAD section at 0x80057280), reads
`nm`, and checks that every non-alias symbol is at its listed address and the
end is 0x800C7E30. It passes.
Toolchain notes: with -fno-common GCC 2.7.2 emits the objects as zero-filled .data
in source order (COMMON placement order is not stable, so do not rely on it).
GCC word-aligns char arrays and structs, so a byte array that starts off a word
boundary is emitted as leading `u8` scalars plus a `<name>_bN` array.

## candidate_globals.h differences
D_8006782C and D_8006784C are not reached from code. The instructions behind them
(`lui 0x8007` + `0x782C`/`0x784C`) resolve to 0x8007782C/0x8007784C, which are in the
layout; the candidate addresses look like a hi/lo carry mistake and are left out.
D_800C33BC is now found from code (base 0x800B9378 + 0x8000 + 0x2044 across blocks).

## Limits
Sizes other than memset/bzero clears are inferences. Struct members accessed by
constant addresses are separate symbols unless a clear call covers the struct.
